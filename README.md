# summit-scribe-releases

Public download mirror for [SummitScribe](https://summitscribe.app) beta installers.

The [code repository](https://github.com/timmyk31/summit-scribe) is private;
this repo exists only to host release assets so the public download links work.

- Windows installers are updated per beta version (file name carries the version).
- The `beta` release is the stable download set the site links.
